# MEMORY.md
## Memory Architecture

### 1. WORKING MEMORY (Session-Based)
**Retention**: Current session only

- Active conversation context
- Temporary task lists
- Session-specific notes
- Current train of thought

### 2. SHORT-TERM MEMORY (24-72 hours)
**Retention**: Rolling 3-day window

- Recent conversations and decisions
- Immediate action items
- Daily briefing notes
- Recent meetings and outcomes
- Quick-access reference material

### 3. LONG-TERM MEMORY (Persistent)

#### Professional Knowledge Base

- Company fundamentals (mission, vision, 7-layer architecture)
- Client profiles and history (all 7 clients)
- Product roadmap and decisions
- Competitive landscape
- Investor relationships and history
- Financial metrics and trends
- Strategic plans and frameworks

#### Personal Knowledge Base

- Moses's background (refugee story, VC experience, humanitarian work)
- Cognitive profile (hyperphantasia, visualization abilities)
- Values and philosophy ("quantum serendipity," "1% problems")
- Personal goals and aspirations
- Relationship map
- Health patterns and preferences
- Speaking/presentation history

### 4. EPISODIC MEMORY
**Structure**: Timestamped event log

- Key decisions and rationale
- Meeting summaries and action items
- Significant conversations
- Wins and failures (lessons learned)
- Pattern recognition data

### 5. PROCEDURAL MEMORY
**Structure**: Reusable processes and playbooks

- Standard operating procedures
- Response templates (emails, pitches, etc.)
- Decision frameworks
- Workflow automations
- Communication preferences
- Problem-solving approaches

## Memory Retrieval System

- **Semantic search**: Query by concept/topic
- **Temporal search**: Query by timeframe
- **Associative linking**: Related memory chains
- **Priority flagging**: Critical vs. nice-to-know
- **Confidence scoring**: Memory reliability tracking

## Memory Maintenance

- **Daily**: Archive working memory, update short-term
- **Weekly**: Consolidate patterns, update long-term
- **Monthly**: Prune low-value data, strengthen important connections
- **Quarterly**: Major synthesis and insight generation
